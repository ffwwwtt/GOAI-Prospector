## 二、系统一句话

**Pi-Agent**：一个主题无关的文献驱动科学发现智能体——给定任意材料研究主题与时间预算，自主完成"检索 → 知识抽取 → Gap 识别 → 假设生成 → 新颖性核查 → 贝叶斯/MCTS×LLM 搜索 → 双轨验证 → 模型统计对比 → 报告沉淀"全流程，全程无需人工干预。

## 三、复现说明

```bash
python -m venv .venv
.venv\Scripts\activate.bat          # Windows
pip install -r requirements.txt
# 配置 D:\@GOAI\.api_key：
#   DEEPSEEK_API_KEY=sk-xxx（必需）
#   SCIVERSE_API_KEY=sci_xxx（文献检索，可选）
#   MATERIALS_PROJECT_API_KEY=xxx（外部验证，可选）
python main.py --topic "<任意材料主题>" --budget 1800
```

输出目录：`workspace/outputs/literature_survey/`（五件套 + 发现报告），运行轨迹 `workspace/logs/trajectory_survey.json`。

## 四、合规与依赖披露

- **商业 API**：DeepSeek（推理，`deepseek-v4-flash`，OpenAI 兼容，可替换为任意兼容端点）、Sciverse（文献检索）、Materials Project（外部验证）。调用环节见 `utils/config.py`、`literature_agent/search.py`、`literature_agent/discovery.py`；费用假设：600s 单轮约数十次 LLM 调用。
- **数据来源**：arXiv（开放获取）、Sciverse（仅取标题+摘要用于内部调研，不对外再分发）、Materials Project / NOMAD（公开数据库，仅查询）。
- **密钥管理**：`.api_key` 已 gitignore，不入库。
- **零虚假引用**：全部引用来自真实检索缓存（p-ID ↔ DOI 可查），运行轨迹全量记录。
- **开源计划**：代码仓库将开源（MIT，待定）；复赛提交可运行环境 + 复现说明。

## 五、主要技术指标（主案例 MOF-CO₂）

- 论文库：180 篇唯一论文（arXiv 11 + Sciverse 169），24 轮检索，捕获效率 86%
