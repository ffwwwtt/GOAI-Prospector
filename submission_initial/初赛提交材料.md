> **项目名称**：Prospector —— 材料科学文献驱动的构效关系自主发现智能体
> **赛道方向**：方向三 · 材料科学文献驱动的科学发现智能体（基本任务 + 路线 A：构效关系发现）
> **调研主题（主案例）**：MOF 材料用于 CO₂ 捕获；另完成三个独立主题端到端验证

## 一、项目摘要

本方案构建了一个**以 LLM 为核心、端到端自主运行、主题无关**的文献驱动科学发现智能体（Prospector）。在有限时间预算内，Agent 自主完成「**文献检索 → 知识抽取 → 知识图谱撰写 → Research Gap 识别 → 构效关系假设生成 → 新颖性核查 → 贝叶斯/MCTS×LLM 搜索 → 双轨验证 → 模型统计对比 → 报告沉淀**」全流程，全程无需人工干预。

**主案例（MOF/CO₂）关键指标**：

| 指标 | 数值 | 证据位置 |
|---|---|---|
| 论文库 | 180 篇唯一论文（arXiv 11 + Sciverse 169） | evidence/mof/paper_summaries.md + evidence/mof/papers.json |
| 知识图谱 | 40 材料 / 87 性质记录 / 14 条构效关系（R1–R14） | evidence/mof/knowledge_graph.md |
| Research Gap | 10 项（含类型/严重度/置信度/证据链/验证方案） | evidence/mof/gap_report.md |
| 构效关系假设 | 8 条，**全部获文献证据链验证**（literature_supported，置信度 0.75–0.99） | evidence/mof/discovery_report.md |
| 搜索规模 | 328 个候选点（贝叶斯，含 LLM 中间评估引导） | evidence/mof/discovery_report.json |
| 模型统计对比 | 缺陷/容量假设 37 样本 R²/RMSE 对比 | evidence/mof/model_comparison.md |
| 引用 | 全部 p-ID ↔ DOI 可查，零虚假引用 | papers.json + 轨迹日志 |

**通用性验证**：另以卤化物钙钛矿带隙（96 篇）、热电 ZT（140 篇）、锂电高镍正极（174 篇）三个独立主题各跑一轮 600s 端到端，全部一次跑通完整闭环（详见第五节与 evidence/）。

**一句话概括**：流程完整（检索→报告全链路真跑通）＋ 发现有效（缺陷类型二象性、水效应符号翻转、双金属非对称等均有证据链）＋ 引用干净（证据可审计、负结果如实披露）＋ 通用（非单主题定制）。

## 二、方案说明：所选方向与科学问题理解

### 2.1 所选方向

- **基本任务**：文献调研 Agent（必做，占比 50%）
- **进阶路线**：**路线 A —— 构效关系发现**（占比 50%）

### 2.2 科学问题理解

材料科学的知识高度沉淀于非结构化文献——组分、结构、工艺与性能之间的关联大量散落在数十年论文中，人工阅读的覆盖能力与大模型时代的文献规模形成根本落差。本项目要解决的核心问题是：

> **如何让一个 Agent 从文献出发，自主完成"检索 → 抽取 → Gap 识别 → 假设 → 搜索 → 验证 → 报告"闭环，并产出可证伪、可追溯、可统计验证的构效关系发现？**

以主案例 MOF/CO₂ 为例，领域存在三个公认的结构性问题，恰好构成 AI 介入点：

| 问题 | 具体表现 | 本项目的处理 |
|---|---|---|
| 知识碎片化 | 容量/选择性/吸附热分散在上千篇论文中 | Agent 自建知识图谱（40 材料/87 数值/14 关系），全部带论文 ID |
| 结论矛盾 | 同一材料不同合成路线性能差异巨大（如 MOF-74(Ni) 容量 3.0 vs 8.3 mmol/g） | 图谱审计自动检出数值冲突 → 矛盾型 Gap；Agent 判断冲突真伪（热电 Mg₃Sb₂ 温度差异被正确判为假冲突） |
| 权衡关系未被刻画 | 容量-选择性-再生能耗 Pareto 前沿无定量结论 | 生成可检验假设 + 模型统计对比 |

### 2.3 切片选择（聚焦而非贪多）

本项目聚焦"**文献驱动的构效关系发现闭环**"这一可探索、可验证的切片：给定任意材料主题与时间预算，Agent 自主完成全流程并产出带证据链的发现信号。主案例限定在 MOF/CO₂ 单主题内做深做透，同时通过三个独立主题证明系统通用性——符合赛题"切勿贪多，扎实做透一条"的指导。

## 三、技术路线概述

### 3.1 总体流程（Agent 自主闭环）

```
阶段一（基本任务）：多源检索 → 覆盖审计 → 深度阅读（Sciverse/PDF/arXiv 回退）
  → 摘要整理 → 知识图谱撰写（Markdown）→ 图谱审计（冲突/重复/溯源）
  → Research Gap 识别 → 结构化调研报告（含 DOI 证据链）
阶段二（路线 A）：假设生成（LLM）→ 系统性新颖性核查（known/partial/new）
  → 贝叶斯优化 / MCTS × LLM 融合搜索（中间候选评估与剪枝）
  → 双轨验证（无机库 MP/NOMAD/OQMD / 文献证据链）
  → 模型统计对比（基线/候选/经典模型 R²-RMSE）→ 发现报告 + 科学解释
       ↑ 跨轮记忆（MEMORY.md + 反思）驱动下一轮迭代
```

### 3.2 技术架构（Prospector）

| 层 | 组件 | 说明 |
|----|------|------|
| 入口 | main.py | 参数解析（--topic/--budget/--output/--fresh）+ 预算控制 + 异常处理 |
| 决策核心 | prospector/agent.py | Prospector 主循环：ReAct + 事件驱动 + 状态机 + 会话 checkpoint |
| LLM 层 | prospector/llm.py | DeepSeek（OpenAI 兼容），24 个工具 schema，JSON 修复与重试 |
| 工具层 | prospector/tools.py + _tools_impl.py | **24 个工具**：通用 10 + 文献调研 8 + 发现 6 |
| 提示词 | prospector/prompts.py | 两阶段提示词 + 预算策略 + 验证走工具等硬约束 |
| 检索层 | literature_agent/search.py | arXiv + Sciverse 多源检索、缓存、检索审计（search_log.jsonl） |
| 解析层 | literature_agent/parser.py | 双引擎：MinerU（可选）→ markitdown_utils（本地，离线可复现）回退 |
| 抽取/审计 | literature_agent/extractor.py | Markdown 知识图谱解析 + 数值冲突/重复/溯源审计 |
| 发现层 | literature_agent/discovery.py | 贝叶斯（k-NN 代理+UCB）/MCTS、双轨验证、新颖性核查、模型对比、Slack 经典模型拟合 |
| 本地解析 | markitdown_utils/ | markitdown 裁剪版（PDF/DOCX/HTML，MIT） |
| 环境 | vendor/bash/ | MSYS2 Git Bash（Windows 兼容） |

### 3.3 关键设计决策

| 设计决策 | 理由 |
|---|---|
| 不构建 JSON 知识图谱，由 Agent 撰写 Markdown 图谱 | LLM 从自然语言推理关系比填充结构化模板更可靠，且图谱可被专家直接阅读核验 |
| 双引擎 PDF 解析 + arXiv 标题回退 | 兼顾解析质量与离线可复现；无链接论文按标题自动去 arXiv 找全文 |
| 确定性打分与 LLM 采样分离 | 搜索打分由文献数值确定性计算（可复现）；LLM 负责推理决策，结论带证据链可独立核验 |
| 验证统一走工具（validate_discovery） | 验证状态/证据链写入 hypotheses.json，构成可审计记录 |
| 新颖性不采信 LLM 自评 | check_novelty 反查文献库判定 known/partial/new，输出边界说明 |
| 跨轮记忆 + 反思 | 多轮运行间继承结论、积累证据，是"增量"的载体 |
| 主题无关 | 检索词/材料/性质/Gap/假设全部运行时生成；性质映射覆盖通用材料属性（中英双语） |

## 四、基本任务：文献调研 Agent 及产出

### 4.1 检索与筛选（四主题实证）

| 主题 | 轮次 | 唯一论文 | 来源 | 年份 |
|---|---|---|---|---|
| MOF/CO₂ 捕获（主案例，两轮迭代） | 91 轮（深化轮） | 180 | Sciverse 169 + arXiv 11 | 2016–2025 |
| 卤化物钙钛矿带隙稳定性 | 24 轮 | 96 | Sciverse 80 + arXiv 16 | 2016–2024 |
| 热电材料 ZT 优化 | 28 轮 | 140 | Sciverse 96 + arXiv 44 | 2011–2026 |
| 锂电高镍正极容量保持率 | 33 轮 | 174 | Sciverse 174 | — |

每轮检索的查询、来源、结果数、耗时记录于 search_log.jsonl；assess_search_coverage 确定性评估唯一论文数/边际收益并给出"继续/停止检索"建议。

### 4.2 知识抽取与图谱审计

- Agent 以 Markdown 撰写知识图谱（材料/性质/数值/单位/条件/关系/论文 ID）；主案例 40 材料、87 性质记录、14 条跨体系关系（R1–R14）；
- audit_knowledge_graph 自动检测：数值冲突（→矛盾型 Gap 候选）、材料重复写法、溯源缺失；主案例溯源缺失 = 0；
- 热电主题审计检出 1 处"数值冲突"（Mg₃Sb₂ 不同温度 ZT），Agent 正确识别为假冲突——体现科学判断力。

### 4.3 Research Gap 识别（Gap 清单 + 证据链）

主案例 10 项 Gap，每条含类型（矛盾/缺失连接/未探索）、严重程度、置信度、证据（p#）、验证方案。节选：

| # | Gap | 类型 | 严重度 | 核心证据 |
|---|---|---|---|---|
| G1 | MOF-74(Ni) 容量跨文献差 2.8 倍，合成-缺陷-容量映射缺失 | 矛盾 | 高 | p17 vs p29 |
| G2 | 双金属非对称非单调协同机制未解释 | 矛盾 | 高 | p29（Ni6Co1<纯Ni） |
| G7 | 缺陷效应方向依赖类型（占位 vs 造孔），无统一框架 | 矛盾（新） | 高 | p121 vs p122 |
| G8 | 水效应方向依赖吸附机制（物理 vs 化学），缺统一相图 | 矛盾（新） | 高 | p30 vs p135/p158/p164 |
| G9 | 循环级性能（TSA/VSA 工作容量、再生能耗）与描述符关系缺失 | 未探索（新） | 高 | p137/p154 |
| G3-G6/G10 | OMS 密度-湿度权衡、胺负载-孔道定量关系、孔径-压力-容量统一描述等 | 缺失/未探索 | 中 | 详见 gap_report.md |

新颖性不靠 LLM 自说自话：每条 Gap 由证据结构支撑（矛盾结论并存、单点证据、定量维度缺失）。

### 4.4 调研报告生成

主案例报告含：执行摘要 / 六大材料体系综述 / 关键材料-性质对比表（含数值与来源）/ 10 项 Gap 清单 / DOI 参考文献表（核心证据链 15 条）。四主题报告均保存在 evidence/ 对应目录。

### 5.2 增量迭代（版本演进）

| 版本 | 关键增量 |
|---|---|
| v1（初始） | 完整四层架构、基本任务全流程、预算/记忆/checkpoint |
| v2 | NOMAD 验证接入 + MP 查询修复；知识图谱审计、双轨验证、全文深度阅读、检索覆盖审计 |

增量的实证：主案例从 120 篇（首轮）扩展至 180 篇（第二轮），假设从 5 条扩展至 8 条，全部文献证据链验证通过；知识图谱从 v1.0 升级至 v2.0（新增缺陷工程、DAC、湿烟气等维度）。

### 5.3 通用性设计（无硬编码主题）

1. 主题由 --topic 驱动，检索词/材料/性质/Gap/假设全部运行时生成；
2. 性质映射覆盖通用属性（带隙/容量/导热/介电/硬度/熔点/模量/热电/离子电导/强度/密度等），中英双语匹配；
3. 材料识别支持化学式、MOF 家族、聚合物缩写（PVDF/PEO 等），元素+家族签名归一化；
4. 数值单位覆盖物理/电化学/力学单位（eV、mmol/g、W/mK、S/cm、GPa、mAh/g、Å 等）；
5. 双轨验证自适应：无机晶体走 MP/NOMAD/OQMD；有机/框架材料走文献证据链（≥2 篇独立论文）。

## 六、路线 A Proposal：构效关系发现

### 6.1 方法流水线

```
generate_hypotheses（LLM 生成假设）
  → check_novelty（反查文献库：known/partial/new + 边界说明）
  → run_discovery_search（贝叶斯/MCTS × LLM：中间候选合理性评估、剪枝引导）
  → validate_discovery（双轨：无机库 / 文献证据链）
  → run_model_comparison（基线 vs 候选 vs 经典模型 R²/RMSE）
  → generate_discovery_report（发现清单 + 证据链 + 科学解释）
```

### 6.2 LLM 与搜索的深度融合（赛题核心要求）

1. **假设种子**：LLM 从知识图谱关系与 Gap 生成候选假设（材料×性质×预期关系×置信度）；
2. **搜索空间构建**：由文献数值的稳健区间（Tukey IQR）自动界定，非人工设定；
3. **中间结果评估**：贝叶斯初始种群与每 10 轮方向由 LLM 评估科学合理性（实测：离谱候选被打 0 分）；MCTS 节点由 LLM 判定是否值得探索（不可行分支分值减半）；
4. **证据驱动剪枝**：Agent 依据搜索反馈决定补检索方向（如 MOF 第二轮补缺陷工程/DAC/湿烟气 46 篇）；
5. **反例与负结果识别**：识别"水促进"（胺型）反例、双金属非单调反例、数据库零覆盖负结果。

评估次数写入 search_hN.json 的 llm_guidance_calls，构成可审计的融合证据。

### 6.3 验证方案（三层）

| 层 | 方法 | 状态 |
|---|---|---|
| 双轨验证 | 无机库（MP/NOMAD/OQMD）+ 文献证据链（≥2 篇独立论文 → literature_supported） | ✅ 主案例 8/8、锂电 5/5 等 |
| 模型统计对比 | 均值/线性（基线）vs 二次/多特征（候选）R²/RMSE + LLM 解释 | ✅ MOF n=37、钙钛矿 n=13、热电 n=9 |
| 经典模型对照 | Slack 带隙-温度模型拟合器（classical_model="slack"），工具经合成数据自检（R²=0.994） | ✅ 机制就绪；钙钛矿语料缺 (T,E_g) 配对数据，执行记录为诚实的"数据不足"（见 evidence/perovskite/slack_model_comparison.md） |

### 6.4 可解释性（拒绝黑箱）

主案例核心发现均附机制解释：

- **缺陷类型二象性**（置信度 0.98）：甲酸盐缺陷（占位 OMS）抑制吸附 vs 配体缺失缺陷（造孔）容量 +50%——统一了 Nat Commun 2023 与 CEJ 2023 的矛盾结论（p121 vs p122）；
- **水效应二象性**：物理吸附 MOF 湿/干比 0.87（水竞争负效应）vs 化学胺 MOF 1.25（碳酸氢盐路径正效应），符号翻转由吸附机制决定（p30 vs p135/p136/p158/p164/p168）；
- **双金属非对称协同**：Ni1Co1 最优 8.30 mmol/g，但 Ni6Co1 < 纯 Ni——挑战"双金属总优于单金属"朴素预期（p29）。

### 6.5 新知与已知的区分

check_novelty 反查文献库输出边界说明并修正新颖性：热电 2 条 new、锂电 4 条 new（热点空白）；经典领域（MOF 等）多为 known/partial（如实标注为复现/增量）。发现报告正文逐条标注「新知/已知：🆕全新 / 🟡部分已知 / 🔁已有报道」。

## 七、初步实验结果与可行性验证

### 7.1 主案例（MOF/CO₂）

- 8 条假设全部 literature_supported（置信度 0.75–0.99）；贝叶斯搜索 328 候选点；
- 2 项定量元分析：孔径-压力窗口（11 点，Pearson r=0.690）；水效应二象性（物理 0.87 vs 化学 1.25，符号翻转显著）；
- 模型统计对比：缺陷/容量假设 37 样本，输出基线 vs 候选 R²/RMSE（候选=基线，如实记录"无提升"——对应假设的统计支撑评估）；
- 外部验证：MP/NOMAD/OQMD 对 MOF 吸附性质覆盖为 0——如实记录为负结果，并转化为方法论 Gap（无机数据库缺乏杂化材料吸附条目）。

### 7.2 跨主题验证（通用性）

| 主题 | 论文 | 知识图谱 | Gap | 假设 | 新颖性 | 验证 |
|---|---|---|---|---|---|---|
| 钙钛矿带隙 | 96 | 6 材料/5 性质 | 6 | 5 | 1 new/2 partial/2 known | 3 supported / 2 inconclusive |
| 热电 ZT | 140 | 27 材料/35 数值 | 7 | 4 | 2 new/2 known | 3 supported / 1 inconclusive |
| 锂电正极 | 174 | 17 材料/17 性质 | 6 | 5 | 4 new/1 partial | 5 supported |

四主题均一次跑通完整闭环；arXiv 全文回退在钙钛矿/热电主题真实命中（86k/61k 字符全文）。
