# 跨主题验证报告 —— 通用材料文献 Agent 的证据

> 目的：证明本 Agent 是**主题无关**的通用材料文献搜索/发现系统，而非针对单一主题（MOF/CO₂）的定制。

---

## 1. 验证设计

四个材料类别、四种不同性质类型，各自独立运行（独立内存、缓存、产物），600s 时间预算（MOF 主案例另含 1800s 深化轮）：

| # | 主题 | 材料类别 | 性质类型 |
|---|---|---|---|
| 主案例 | MOF 材料用于 CO2 捕获 | 框架材料（有机/无机杂化） | 吸附容量 / 选择性 / 热 / 稳定性 |
| 2 | 卤化物钙钛矿带隙与稳定性 | 杂化/无机半导体 | 带隙 / 相稳定性 |
| 3 | 热电材料 ZT 优化 | 无机热电半导体 | ZT / 热导率 / 功率因子 |
| 4 | 锂电高镍正极容量保持率 | 电化学氧化物 | 容量保持率 / 电压窗口 |

## 2. 各主题运行结果

### 主题 2：halide perovskite solar cells band gap stability（24 轮）

- 96 篇唯一论文（Sciverse 80 + arXiv 16）；知识图谱 6 材料/5 性质；6 个 Gap
- 5 条假设 → 新颖性核查（1 new / 2 partial）→ 2 条贝叶斯搜索（**LLM 引导 12 次**）→ 批量验证（3 literature_supported / 2 inconclusive）
- **arXiv 全文回退首次真实命中**：p26 下载并解析 86k 字符全文（热力学带隙模型）
- 模型对比如实报告"定量样本不足"（1 样本）→ 该领域定量动力学数据稀缺本身就是 Gap 证据

### 主题 3：thermoelectric materials ZT optimization（28 轮）

- 140 篇唯一论文（96 + 44）；知识图谱 27 材料/35 数值；7 个 Gap
- 4 条假设 → 新颖性核查（**2 new**）→ 贝叶斯搜索（LLM 引导 4 次）→ 验证（3 literature_supported / 1 inconclusive）
- 知识图谱审计检出 1 处"数值冲突"（Mg3Sb2 不同温度 ZT），Agent 正确识别为**假冲突**（温度条件不同）——体现科学判断力
- 模型对比：9 样本，候选=基线（如实记录"无提升"）

### 主题 4：lithium-ion battery high-nickel cathode capacity retention（33 轮）

- 174 篇唯一论文；知识图谱 17 材料/17 性质；6 个 Gap（含 2 个矛盾型高优先级）
- 5 条假设 → 新颖性核查（**4 new**，该领域热点空白）→ 搜索 → **全部 5 条 literature_supported**
- 调研报告含材料-性质对比表（保持率 19%→95% 跨策略对比）与 DOI 参考文献表

### 经典模型对照（Slack 模型）—— 路线 A 统计验证闭环

路线 A 验证标准要求"新规律统计优于前人公式"。系统已实现 `run_model_comparison(classical_model="slack")`：拟合 **Slack 带隙-温度模型**（`E_g(T)=E_g0−S·ħω·[coth(ħω/2k_BT)−1]`）作为经典基线，与线性/二次候选同口径输出 R²/RMSE + LLM 解释。工具经合成数据自检（R²=0.994，参数可恢复）。当前钙钛矿语料缺少（温度, 带隙）配对数据，执行结果为诚实的"数据不足"（详见 `evidence/perovskite/slack_model_comparison.md`）——该缺口本身印证了知识图谱标注的"带隙漂移速率定量数据缺失"Gap；数据补齐格式与执行命令见该文件。

**主案例 LLM 引导复跑**：MOF 主案例 8 条假设已用 LLM 引导版贝叶斯搜索复跑（共 16 次引导评估，逐条记录见 `evidence/mof/llm_guided_search.json`），与跨主题验证形成一致的 LLM×搜索融合证据。

## 3. 通用性设计依据（无硬编码主题）

1. **主题由命令行驱动**：`--topic` 传入，检索词/材料/性质/Gap/假设全部由运行时数据生成；
2. **性质映射覆盖通用材料性质**：带隙、容量、选择性、热/离子/电子导率、介电、硬度、熔点、模量、热电优值、强度、密度、压力、温度等，中英文双语匹配；
3. **材料识别通用**：化学式、MOF 家族、聚合物缩写（PVDF/PEO 等）均支持，元素+家族签名归一化匹配；
4. **数值单位覆盖广**：mmol/g、eV、W/mK、S/cm、GPa、mAh/g、Å 等物理/电化学/力学单位；
5. **双轨验证自适应**：无机晶体走 MP/NOMAD/OQMD 数据库；有机/框架材料走文献证据链（≥2 篇独立论文）；
6. **可复现性**：搜索打分由确定性文献数值计算（材料覆盖率 + 共现 + 数值贴近度），不依赖 LLM 采样；随机种子与复现说明见 00。

## 4. 结论

四个性质类型完全不同的主题均一次跑通完整闭环（检索 → 覆盖审计 → 深度阅读 → 知识图谱+审计 → Gap → 假设 → 新颖性核查 → LLM×搜索融合 → 批量双轨验证 → 发现报告 → 记忆收尾），且各主题的新颖性判定符合领域直觉（经典领域多为 known/partial，热点空白多为 new）。证据表明该系统为**通用材料文献 Agent**，可直接应用于任意材料研究主题。

原始运行产物见本包 `evidence/`（各主题的调研报告、新颖性核查、模型对比等）；运行轨迹见 zip 内 `运行证据/运行轨迹/`（当前保留 battery 主题轨迹；其余主题轨迹因 `--fresh` 清理机制未留存，但完整产出归档与证据链均在本包可核验，也可按复现说明重新生成）。
