# Slack 模型对比 —— 路线 A 统计验证闭环（执行记录）

> 生成：2026-08-02 | 主题：卤化物钙钛矿带隙稳定性

---

## 1. 目的

路线 A 验证标准要求"新规律须在统计指标上优于前人成果（如更高 R² / 更低 MSE）"。为此实现经典模型对照通道：以 **Slack 带隙-温度模型**（`E_g(T) = E_g0 − S·ħω·[coth(ħω/2k_BT) − 1]`，Slack, 1970s）为经典基线，对比候选构效关系。

## 2. 工具能力（已实现）

`run_model_comparison(hypothesis_index=N, classical_model="slack")` 会在常规基线/候选对比之外，额外拟合 Slack 模型并输出：

- 拟合参数：`E_g0`、`S·ħω`、`ħω`
- 统计指标：R²、RMSE（与线性/二次候选同口径）
- 样本要求：≥5 个（温度, 带隙）配对样本

**工具自检**（合成 Slack 曲线 + 高斯噪声，9 个样本）：拟合 R²=0.994、RMSE=0.006 eV，参数可恢复——拟合器数值正确。

## 3. 当前语料执行结果（诚实记录）

对钙钛矿知识图谱执行抽取：仅得到 **2 个带隙样本（1.73 eV、1.52 eV），均无温度描述符** → Slack 拟合配对样本数 = **0**，判定 **数据不足，本次无法执行**。

```
Slack 模型：insufficient——需要 ≥5 个（温度, 带隙）配对样本
```

## 4. 结论与意义

1. **这本身是一个被工具验证的数据缺口**：语料中"带隙漂移速率 / 温度依赖"定量数据缺失（与知识图谱四、数据缺口第 1 条一致），说明该主题的定量动力学数据在现有文献检索覆盖内确实稀疏——这是 Gap 分析的真实性证据。
2. **闭环机制已就绪**：一旦知识图谱补充温度依赖数据，即可一键执行经典模型对照，无需改代码。

## 5. 数据补齐方式（下轮运行）

在知识图谱中按以下行格式补充（≥5 行，温度与带隙同材料配对）：

```markdown
| 材料 | E_g (eV) | T (K) | 来源 |
|---|---|---|---|
| MAPbI3 | 1.63 | 100 | pXX |
| MAPbI3 | 1.57 | 300 | pXX |
...
```

然后执行：

```bash
run_model_comparison(hypothesis_index=0, classical_model="slack", baseline_model="Slack model")
```

输出将给出：Slack（经典）vs 线性（基线）vs 二次（候选）三模型 R²/RMSE 对比 + LLM 科学解释（经典模型为何适用/失效）。
