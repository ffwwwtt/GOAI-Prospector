# 路线 A：构效关系发现（Structure-Property Relationship Discovery）

## 初赛 Proposal

---

## 1. 目标

从文献出发，自主发现（材料结构/工艺参数 → 性质）的定量构效关系。产出的每条发现必须满足：

- **可证伪**：有明确预期关系与可检验方向；
- **可追溯**：证据链逐层指回具体论文/数据库记录；
- **可验证**：双轨验证（数据库 / 文献证据链），统计指标（R²/RMSE）与基线/前人公式对比；
- **可解释**：附物理/化学机制解释，拒绝黑箱输出。

## 2. 与评审标准的对应

| 评审要点 | 本项目方案 |
|---|---|
| LLM 与搜索的融合深度 | LLM 参与假设生成、新颖性核查、搜索中间候选评估与剪枝、模型解释——而非仅生成代码 |
| 机制解释的说服力 | scientific_explanation + 模型对比解释 + 负结果如实分析 |
| 新知与已知分清 | check_novelty 系统性反查文献库，输出 known/partial/new 边界说明 |
| 验证标准（优于前人） | run_model_comparison：新规律 R²/RMSE vs 基线/前人公式 |
| 零虚假引用 | 引用全部来自检索缓存，审计工具保证溯源缺失为 0 |

## 3. 方法流水线

```
generate_hypotheses
  → check_novelty（known/partial/new + 边界说明 + 新颖性修正）
  → run_discovery_search（贝叶斯 / MCTS × LLM）
  → validate_discovery（双轨）
  → run_model_comparison（基线 vs 候选统计对比）
  → generate_discovery_report
```

## 4. 搜索算法设计

### 4.1 贝叶斯优化

- 代理模型：加权 k-NN 预测均值与方差；
- 采集函数：UCB（exploration 系数随迭代衰减）；
- 搜索空间：由文献数值的稳健区间（Tukey IQR）定义，抗离群值；
- **LLM 融合**：初始种群由 LLM 评估合理性并加权；每 10 轮 LLM 评估搜索方向，引导聚焦/剪枝。

### 4.2 MCTS

- 完整 select / expand / simulate / backprop；
- **LLM 融合**：每 50 次迭代由 LLM 判定节点科学合理性——不可行分支分值减半，可行分支加分。

### 4.3 证据打分

`证据分数 = 材料覆盖率 + 材料×性质共现 + 数值贴近文献报告值`，全部基于 Agent 自写的知识图谱/全文缓存确定性计算，可复现。

## 5. 验证与统计标准

### 5.1 双轨验证

- **无机晶体**：Materials Project（band gap / formation energy，含元素系回退）、NOMAD（公开 API，材料存在 + 电子数据）、OQMD（本地缓存）。
- **有机/框架材料**：文献证据链——知识图谱中 ≥2 篇独立论文支持 → `literature_supported`。
- **覆盖性说明**：数据库无记录时如实声明，不产生虚假命中。

### 5.2 统计对比（对应"新规律优于前人"）

- 基线：均值模型 / 最优单描述符线性回归；
- 候选：二次回归 / 多特征线性回归；
- 指标：R²、RMSE，输出提升量与结论；
- LLM 解释：新规律揭示的物理机制 + 前人公式为何失效。

### 5.3 负结果处理

负结果（如"候选与基线无显著差异"）如实记录并给出原因分析——被清晰解释的负结果同样有评审价值。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 文献数据稀疏，样本不足 | 深度阅读全文补充定量行；样本 <5 时工具明确提示 |
| LLM 自评新颖性不可信 | check_novelty 以文献反查为准 |
| 无机数据库不覆盖有机材料 | 文献证据链通道 + 覆盖性说明 |
| 经典模型对比缺乏现成公式 | baseline_model 参数由 Agent/用户指定，统计基线自动兜底 |
